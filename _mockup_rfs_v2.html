Design Rationale & Interaction Model

  • Left panel: Floorplan list is the primary navigation. Clicking a floorplan reloads all three sections (Renewals tiers, New Leases tiers, Market Comps) simultaneously. Property Summary and Inducements collapse to save space.
  • Summary strip: Always-visible header shows Budget/Actual/Reforecast KPIs + Left-to-Budget split by lease type so users always have context without scrolling.
  • Both lease types visible: Renewals and New Leases sections are stacked. Users can edit both without toggling. Each section has its own Add + Save buttons inline.
  • NER live-update: Typing in Rate or Conc. instantly recalculates NER in that row and the weighted-avg footer.
  • 💾 Save All Tiers (top right) commits ALL pending edits across both lease types at once. Individual section Save buttons commit just that lease type.
  • Market Comps: Auto-filtered to the selected floorplan's Compare-As type. Include toggle persists immediately. Totals always visible below the scrollable list.
