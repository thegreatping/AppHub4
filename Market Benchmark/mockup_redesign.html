🎨 Redesign Mockup — Market Benchmark for AppHub 4.0 This is a static HTML prototype. Hover purple ● dots for design annotations. Click to expand/collapse notes ▼

Left Comp Panel

The comp list is promoted from a flat list to a persistent left panel — always visible regardless of which tab is active. Clicking a comp name changes the subject for all tabs simultaneously. The current subject property appears in the module header pill.

Tab Bar + Header

Tabs match AppHub's standard pattern (cyan underline, uppercase labels). The subject property pill in the header always shows what you're viewing. Switching subjects from the comp panel auto-updates all tabs — no dropdown hunting.

Floor Plans → Data Table

Floor plans use the AppHub data-table pattern instead of a custom grid. Column widths are uniform. Clicking a row opens the slide-out (matching PDM's detail overlay). Auto-save on blur. Collapsible sections.

Assign Comps → Drag List

Comps are shown as a drag-to-reorder list with explicit ⠿ grip handles — same pattern as AppHub maintenance module registry. Add via inline search typeahead. Remove via trash button on hover.

Markets Tab → KPI Cards

Aggregated market data is displayed as KPI summary cards at the top (occupancy, rent, prelease, concessions) with a detailed comparison table below — matching AppHub's usage log analytics pattern.

Quick-Add + Filter Bar

Each tab has a Quick Add form and filter bar matching AppHub standards. "Show inactive" checkbox is consistent across tabs. Column selector gear on tables follows PDM pattern.
