Clicking any KPI card jumps directly to the Tiers tab for that metric's drill-down.

How Tiers Work

  • Add (＋): Inserts a new row seeded with the last tier's rate. TIER_ORDER auto-increments.
  • NER column: Recalculates live as you type Rate or Annual Special (NER = Rate − Concession/12).
  • Save Tiers / 💾 Save All: Persists all edited rows to FORECAST_FORECAST_TIERS simultaneously. RATE_EXTENDED, NER_EXTENDED, MODIFIED_BY, DATE_MODIFIED all computed server-side.
  • Delete (🗑): Confirms, then hard-deletes the row.
  • Lease toggle in the top bar controls which lease type is shown across all three columns simultaneously.

How Market Comps Works

  • Comps are automatically filtered to the selected floorplan's Compare-As type (e.g. "2x2" for EMERALD). Switching floorplans reloads the list.
  • Include toggle (✓/✗): Instantly persists FLAG_INCLUDE to FORECAST_COMP_FLOORPLANS and recalculates the totals without a page reload.
  • Excluded rows: Dimmed in the table, excluded from totals. Sold-Out comps count in "All Competitors" but not "Leasing Comps".
  • NER = NER_PRELEASE_FURNISHED. Rows with no data yet show "—".
  • Parent property's own floorplans are filtered out from the list (COMP_PROPERTY_KEY ≠ PARENT_PROPERTY_KEY).
