Module Registry ▼
Central registry of all AppHub modules (applets). Each module has a name, ID, and active/inactive status.

How to use:
  • Toggle status — Click the Active/Inactive badge to enable or disable a module site-wide.
  • Edit name — Click a module name to rename it inline.

Note: Disabling a module hides it from the sidebar for ALL users, regardless of audience grants.

Audience Manager ▼
Controls which users and groups can access each module. Grants are checked at page load — users without a grant won't see the module in the sidebar.

How to use:
  • Select a module — Click a module in the left nav to view its grants.
  • Add a grant — Choose a grant type (Title Group, Email, Property), enter the value, and click Grant.
  • Remove a grant — Click the × button next to any grant to revoke it immediately.

Grant types: Title Group (all employees in that group), Email (individual user), Property (all employees at that property). "Admin" grants give elevated permissions within the module.

User Lookup ▼
Look up any employee to see which AppHub modules they can access — and why. Useful for troubleshooting "I can't see module X" requests.

How to use:
  • Search — Start typing an employee name. Autocomplete suggestions appear after 2 characters.
  • Module grid — Shows all modules with access status: ✓ has access, ✗ excluded, ☐ no access.
  • Toggle access — Click any module box to grant or revoke individual access for that user. Changes take effect immediately.
