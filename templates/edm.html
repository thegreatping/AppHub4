Employee Directory ▼
Read-only view of EMPLOYEE_F — the unified employee fact table rebuilt hourly from Paycom, AD, and Entrata sources. Returns up to 1,000 results.

How to use:
  • Search — Type a name, email, or employee code in the search box. Results filter as you type.
  • Filters — Use the Status, Title Group, and Property dropdowns to narrow results. Default shows Active/On Leave employees.
  • Sort — Click any column header to sort ascending/descending (▲/▼). Click again to reverse.
  • ⚙ Columns — Add or remove any of 106 available columns (all EMPLOYEE_F fields + LEO data). Type in the search box to find columns quickly. Click "Reset to Default" to restore the original 7 columns.
  • 💾 Export — Download the current filtered view as a CSV file with your selected columns.
  • Detail View — Click any employee row to open a side panel showing ALL fields for that person. Press Escape or × to close.

Title Assignments ▼
Maps each Paycom Title to a Title Group used across the BI platform (security, Entrata provisioning, AD exports, reporting). When a new title appears in Paycom that doesn't exist here, employees with that title fall into _UNASSIGNED until mapped.

How to use:
  • Add a title — Enter the exact Paycom title, select or type a Title Group, optionally set Type (PROPERTY/CORPORATE), then click Add.
  • Edit inline — Click any Title Group or Type cell to change it. Title Group shows a dropdown of existing groups + "Enter custom" for new ones. Type is a dropdown (PROPERTY/CORPORATE/None).
  • Bulk assign — Use the checkboxes to select multiple unassigned titles. The header checkbox selects ALL unassigned rows. A blue bar appears where you pick a group + type and click Apply.
  • Sort — Click column headers. _UNASSIGNED rows always stay pinned at the top.
  • Filter — Type in the filter box to find specific titles or groups.
  • Validation warnings — Orange alerts show Title Groups missing Entrata mappings, or orphaned Entrata entries.

Rules: Each Title must be unique (one mapping per title). Multiple titles can share the same Title Group. Changes take effect on the next Employee Update cycle (hourly).

Entrata Mapping ▼
Maps each Title Group to an Entrata Department and Permission Group. The Employee Update uses this mapping to provision Entrata access for each employee.

How to use:
  • Add a mapping — Enter a Title Group (autocomplete available), an Entrata Department, and an Entrata Permission Group, then click Add.
  • Edit inline — Click any Department or Permission Group cell to change it directly.
  • Sort — Click column headers to sort by Title Group, Department, or Permission Group.
  • Filter — Type in the filter box to search across all columns.
  • Delete — Click Delete to remove a mapping. Employees in that group will lose Entrata provisioning on the next cycle.

Rule: Each Title Group should have exactly one row. If a Title Group has no mapping here, employees in that group won't receive Entrata assignments.

Soft Termination Overrides ▼
Keeps terminated employees' AD accounts active beyond the normal 20-day window. Use for consulting arrangements, transitions, or special projects.

How to use:
  • Add an override — Enter the Employee Code, a Reason for the override, and optionally an Expires date. Click Add.
  • Expires date — If set, the override automatically stops applying after that date. Leave blank for indefinite overrides.
  • Deactivate (pause icon) — Temporarily disables the override without deleting it. The employee will be moved to "Terminated" on the next AD sync.
  • Reactivate (play icon) — Re-enables a previously deactivated override.
  • Delete (trash icon) — Permanently removes the override record.
  • Sort — Click any column header to sort the table.
  • Show Inactive — Check the box to reveal deactivated overrides (shown at 50% opacity).

How it works: The Active Employees for AD export checks this list. Anyone flagged here stays in the "Active" AD export instead of being moved to "Terminated."
