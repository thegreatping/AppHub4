Property Directory ▼
Master view of PROPERTY_0 — the authoritative property table with ~190 fields covering identity, staff, status, financials, and more.

How to use:
  • Search — Type a property name, city, school name, or property key.
  • Filters — Use Status (Managed/Dispositioned/Reportable/All), Property Group, and Market dropdowns.
  • Sort — Click any column header to sort ascending/descending (▲/▼).
  • ⚙ Columns — Add or remove any of ~190 available columns. Type in the search box to find columns quickly. Click "Reset to Default" to restore defaults.
  • 💾 Export — Download the current filtered view as a CSV file with your selected columns.
  • Detail View — Click any property row to open a side panel showing ALL fields, grouped by category. Editable fields can be changed directly in the panel.
Property Groups ▼
Manages the PROPERTY_GROUP_0 lookup table. Property Groups organize properties into portfolios for reporting, security, and billing.

How to use:
  • Add a group — Enter the group name and click Add.
  • Edit inline — Click a group name to rename it.
  • Toggle status — Click Active/Inactive to enable or disable a group.
  • Sort — Click column headers to sort.
  • Filter — Type in the filter box to search.

Note: Each property in PROPERTY_0 references a group by name. Renaming a group here does NOT update existing property records — you must also update the properties.

Markets ▼
Manages the MARKETS dimension table. Each property is assigned to a market (city + state) used for geographic reporting and comp analysis.

How to use:
  • Add a market — Enter a city and 2-letter state code, then click Add. The City/State display value is auto-generated.
  • Edit inline — Click any City or State cell to change it.
  • Sort — Click column headers to sort.
  • Filter — Type in the filter box to search.
