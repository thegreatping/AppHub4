Architecture Notes

  • Shell pattern: All modules extend shell.html via Jinja2 inheritance; nav is sticky with SPA-like content swapping.
  • Auth: Entra ID MSAL auth-code flow. DEV_BYPASS=true skips auth in dev. Prod uses Azure AD app registration.
  • SharePoint modules: Cultivate, Peak Link, PAF, Mindset use Graph API (FabricPipelineApp client credentials). Requires Sites.ReadWrite.All (done) + Sites.FullControl.All (pending admin consent for unique-permission lists).
  • Sort pattern: All module tables use th[data-col] sort arrows. Functions exposed via window.sortFn = sortFn due to IIFE scope. Fixed Aug 9.
  • Market Benchmark: Standalone Flask app on port 5055 (separate process). Eventual plan: integrate into AppHub shell.
  • Module audience: Access controlled by MODULE_AUDIENCE table in DB_APP_SUPPORT + EMPLOYEE_F.TITLE_GROUP. No legacy numeric security levels.
