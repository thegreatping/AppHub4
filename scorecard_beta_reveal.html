Leadership Scorecard - Beta Reveal Demo Script

Walk-through checklist for the beta reveal. Check items off as you demo each one. Progress is saved in your browser.

What this app does

The Leadership Scorecard is a quarterly performance snapshot for every active property. Each property gets a Leadership half (what the Property Manager owns) and a Maintenance half (what the Maintenance Supervisor owns). Measures are scored Pass/Fail against stakeholder-approved thresholds; the RM then adds a subjective 0-5 RM Score. The sum of all measures plus RM Score = the property's Overall Score, which feeds the quarterly bonus process.

Where the data comes from

Fourteen measures across six source systems: Entrata (timecard, work orders, P-Card, LEO compliance, training), Reputation.com (REP), RM-entered quarterly inspections (CURB/PUBLICAREAS/MAINT/LOGS), and RM manual entry (RMSCORE/SURVEYS/NOI). A nightly Fabric notebook (NB_LEADERSHIP_SCORECARD_UPDATE) pulls each source, applies the business rule registered in control.SCORECARD_MEASURE_RULES, and writes to dbo.SCORECARD_CORE. If a source has zero rows for the current quarter, the measure shows -- for every property (no stale defaults).

Who uses it, and how

RM sees their own portfolio read-write (can enter RM Score, add notes, request overrides). PM sees their property read-only. Admin sees every reportable property, can impersonate roles, run the pipeline, edit tables, and sign off. RVPs see every property in their region.

What the beta covers

The Leadership Scorecard module is the only beta module in this release. Every other AppHub app is still invite-only until GA. The Scorecard is open to all logged-in users, scoped by role.
